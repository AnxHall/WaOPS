# Correlation

## Objetivo
Agrupar eventos relacionados sem afirmar causalidade sem evidência.

## Sinais
- dependency graph
- temporal proximity
- common host
- common service
- common database
- release/change recent
- repeated fingerprint

## Regra
WaOPS pode sugerir "possível relação" ou "correlação observada", mas não deve afirmar causa automaticamente.
