# WaSupport API Endpoints

## Tickets
- GET `/api/v1/tickets`
- POST `/api/v1/tickets`
- GET `/api/v1/tickets/:id`
- PATCH `/api/v1/tickets/:id`
- POST `/api/v1/tickets/:id/comments`
- POST `/api/v1/tickets/:id/assign`
- POST `/api/v1/tickets/:id/transition`

## Kanban
- GET `/api/v1/support/board`
- GET `/api/v1/support/statuses`
- POST `/api/v1/support/statuses`
- PATCH `/api/v1/support/statuses/:id`
