# Responsive Rules

`designer.md` remains authority for exact breakpoints/visuals.

Engineering requirements:

- no essential action inaccessible on tablet/mobile;
- tables may collapse into card/detail patterns;
- side panels become drawers on narrow screens;
- WaAI popover must not cover primary destructive confirmation;
- Kanban must support horizontal scroll/touch;
- charts need readable fallback sizes;
- navigation must preserve permission/entitlement behavior.
