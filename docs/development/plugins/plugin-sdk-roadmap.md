# Plugin SDK Roadmap

## Stage 1
Internal module contracts only.

## Stage 2
First-party plugin SDK for Wasync modules/integrations.

## Stage 3
Signed external plugins with strict compatibility and security validation.

## Not before
Do not implement external arbitrary plugin execution before:
- permission model;
- sandbox model;
- signing;
- compatibility;
- lifecycle;
- uninstall data policy.
