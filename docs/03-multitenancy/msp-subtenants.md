# MSP / Subtenants

## Objetivo

Permitir que um tenant contratado atenda seus próprios clientes.

## Capacidade adicional

- organizações/clientes finais
- usuários por organização
- recursos vinculados a organização
- tickets
- docs publicadas
- filtros de visibilidade

## Regra

Subtenant não é tenant completo por padrão.
Billing continua no tenant pai, salvo evolução futura.
