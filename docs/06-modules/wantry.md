# Wantry

## Função
Error/application monitoring próprio.

## Conceitos
- project
- DSN-like credential
- ingestion endpoint
- exception
- stacktrace
- environment
- release
- tags
- breadcrumbs
- fingerprint
- issue grouping
- regression
- sampling
- PII scrubbing

## Fluxo
Error → Ingest → Normalize → Group → WaOPS Event → Incident opcional → Ticket opcional
